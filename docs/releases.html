Historique des versions

0.3.2 — 24 avril 2026

  • Install vraiment silencieux : plus de popup Windows pendant l'installation. Le certificat est importé uniquement dans le store TrustedPublisher (suffisant pour VSTO), pas dans Root qui déclenchait un dialog de confirmation forcé par Windows.
Télécharger 0.3.2

0.3.1 — 24 avril 2026

  • Installation en un click (première tentative) : l'installateur importe lui-même le certificat. Plus besoin d'ouvrir PowerShell avant.
Version archivée — utilise la 0.3.2 qui inclut ces changements.

0.3.0 — 24 avril 2026

  • Feedback in-popup : lien « Signaler une erreur » au pied de chaque suggestion, dialog modal avec pré-remplissage du contexte, envoi via presse-papier ou HTTP (selon config).
  • Matching préfixe : propositions partielles avec … en rouge quand aucun pattern complet ne matche.
  • Sum / product / integral sans mot-clé : Sum k 1 n f(x) marche comme lim x 0 f(x).
  • Angle ABC (3 lettres majuscules) proposé avec la notation ∠ABC.
  • Fix : Ctrl+Espace ne coupe plus la span sur un ; ou , à l'intérieur d'un intervalle [0;+∞[.
Version archivée — utilise la 0.3.2 qui inclut ces changements.

0.2.0 — 23 avril 2026

  • Ctrl+Espace force la popup sur ce qui vient d'être tapé (issue de secours quand la détection automatique rate).
  • Bouton « Signaler un souci » dans le ruban : zip log + contexte prêt à envoyer.
  • Bouton « Aide » avec un readme des raccourcis.
  • Alignement : l'équation suit l'alignement du paragraphe (plus de centrage forcé).
  • Fix : position popup fiable même quand le doc contient déjà des équations.
  • Fix : plus de « . » dégénéré quand un rendu LaTeX partiel échoue (fallback propre).
Version archivée — utilise la 0.3.2 qui inclut ces changements.

0.1.0 — 22 avril 2026

  • Première bêta interne. Détection NER des zones math, popup de suggestions, insertion en OMath Word.
Version archivée — utilise la 0.3.2 qui inclut ces changements.
