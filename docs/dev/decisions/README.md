- `[molle]` Fix — [Un sup issu d'un postSign (0⁺) ne doit jamais s'orienter en chapeau](2026-06-22-Fix-orphan-postsign-sup-not-hat.md) — `lim x 0+ ` (espace final ajouté par la détection live) rendait `\lim_{x→0} \hat{+}` (« limite de chapeau-de-plus »). Fix **structurel** (Score intact) : `Token.SignSup` posé sur le sup issu d'un postSign (`Lexer.cs:291`) → la dérivation unaire est supprimée pour ces tokens (`Parser.cs:397`). `lim x 0+ ` → `\lim_{x→0⁺} □` présélectionné.
