**Kind :** Release

## Décision

Bump mineur 0.1.0 → 0.2.0, publication d'un installer aux beta-testeurs (fils
PAP + quelques profs + demandes LinkedIn/Facebook).

## Pourquoi

- Cumul des améliorations depuis 0.1.0 : fix position popup (GUIThreadInfo),

  LaTeX, alignement respecte paragraphe, icône Aide avec readme.

  juste des bugfixes.
- Le versioning restera pragmatique en phase beta : `0.x.y` tant qu'on n'a pas
  validé avec un usage quotidien du PAP + profs.
