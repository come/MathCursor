Guides d'installation

Choisissez votre éditeur : Word en version stable, VS Code et LibreOffice en alpha. Chaque guide commence par le téléchargement, puis le pas-à-pas.

Télécharger pour Word

Télécharger la dernière version (.exe) Toutes les versions

  1. 1. Télécharger l'installateur

    Récupérez MathCursor-Setup.exe via le bouton ci-dessus.

  2. 2. Lancer l'installateur

    Double-cliquez sur le fichier. L'installateur importe lui-même le certificat nécessaire, puis installe le complément dans votre compte utilisateur, sans droits administrateur ni étape PowerShell.

  3. 3. Utiliser

    Ouvrez Word : un onglet MathCursor apparaît dans le ruban. Tapez x2+1/2 dans un document, puis déclenchez la conversion (bouton de l'onglet ou Ctrl+Espace).

Configuration : Windows 10 ou 11, Word 2016+ ou Microsoft 365. Langues d'interface : français, anglais, allemand, espagnol.

Télécharger pour VS Code (choisissez votre plateforme)

Windows 64 bits (.vsix) Linux 64 bits (.vsix) macOS Apple Silicon (.vsix)

  1. 1. Télécharger le .vsix

    Récupérez le .vsix de votre plateforme via les boutons ci-dessus.

  2. 2. Installer dans VS Code

    Palette de commandes (Ctrl+Maj+P) ▸ « Extensions : Install from VSIX… », puis choisissez le fichier. En ligne de commande : code --install-extension <fichier>.vsix.

  3. 3. Utiliser

    Ouvrez un fichier .tex, .latex ou .md. Tapez une sténo (ex. 1/x+1), Ctrl+Espace propose le LaTeX au caret, vous validez.

Configuration : VS Code 1.90+. La popup au caret est disponible sous Windows ; sous Linux et macOS, la conversion se fait via Ctrl+Espace sans la popup au caret pour l'instant. Cohabite avec LaTeX Workshop, sans couplage.

Alpha : les binaires ne sont pas encore signés, votre système peut donc demander une confirmation au premier lancement. Pas encore sur la Marketplace ; Mac Intel, Linux ARM et Windows ARM à venir.

Télécharger pour LibreOffice

Télécharger l'extension (.oxt)

  1. 1. Télécharger le .oxt

    Récupérez MathCursor.oxt via le bouton ci-dessus.

  2. 2. Installer

    Double-cliquez le fichier (ou Outils ▸ Gestionnaire des extensions ▸ Ajouter…), puis redémarrez LibreOffice.

  3. 3. Lier le raccourci

    Outils ▸ Personnaliser ▸ Clavier : choisissez Ctrl+Espace, catégorie Macros LibreOffice ▸ mathcursor, fonction convert_selection, puis Modifier.

  4. 4. Utiliser

    Dans Writer, tapez une sténo (1/2, x^2+1/2, lim x 0 g(x)), sélectionnez-la, Ctrl+Espace et la formule est insérée.

Configuration : LibreOffice 7.0+ (Writer), Windows 64 bits. Le moteur et la popup sont embarqués dans le .oxt, rien d'autre à installer.

Alpha : l'auto-détection (popup au fil de la frappe) demande le modèle de reconnaissance, pas encore embarqué : pour l'instant c'est le mode manuel (sélection + Ctrl+Espace). Syntaxe StarMath best-effort ; versions macOS et Linux à reconstruire sur l'OS cible.
